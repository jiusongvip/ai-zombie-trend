## 四个镜头，按顺序

情侣故事和站上其他所有成片共用同一副骨架——同样的四段分镜、同样的秒数、同样的匹配剪辑；
场景（木屋、灰海岸、雨夜街道、雪夜门口）对所有主体通用。属于情侣版本的，是画面里站着的
是谁，以及那次接触读起来是什么。

| 镜头         | 秒数  | 画面                                                                                                                     |
| ------------ | ----- | ------------------------------------------------------------------------------------------------------------------------ |
| 1 — 两个人   | 0-4   | 幸存者颤抖着站在原地，武器或手里的物件垂在身侧，始终没能用起来。切全景：爱人一动不动地等着，面朝幸存者——并没有攻击。     |
| 2 — 亡者的脸 | 4-6   | 爱人的极端特写。灰白的皮肤、浑浊泛白的眼睛、深色血管、凌乱的头发。可怖，但一眼就认得出是您第二张照片里的那个人。         |
| 3 — 抉择     | 6-10  | 幸存者松手让手里的东西落地，双臂缓缓大大张开。浑浊的眼里有什么熟悉的东西闪了一下，爱人跑过最后几米，双臂紧紧环住幸存者。 |
| 4 — 匹配剪辑 | 10-15 | 就在拥抱的那一瞬间硬切：木屋变成阳光下的金色麦田。两人都健康地活着，两张脸都与参考照完全一致，穿着干净的日常衣物。       |

前十秒冷青灰，最后五秒暖金。色彩变化承担了大部分情绪，两个人的表演只需要稳到让这一刀读起来是同一个拥抱，而不是两段不相干的素材。

## 两张脸是怎么保住的

情侣模板里的身份锁定句点名了四件事，而且对**两个角色**都各说一遍，并在最容易崩的结尾再
重复一次：

- **面部身份**——每张脸各自对齐自己的参考照，而不是把两张脸合成一张。
- **发型与身形比例**——这是让两张年龄相仿的脸读起来是两个不同人的关键。
- **谁是谁**——第一张照片是幸存者，第二张是化丧尸的爱人。模板明确告诉模型：幸存者抬不起
  武器，爱人永远不会绕到幸存者背后，所以两个角色一直分处画面两侧。
- **亡者的样子是画上去的，不是替换**——灰皮肤与浊眼覆盖在*这个人*之上，所以第二幕里您依然
  认得出那是您的爱人。

故事里没有任何地方假设性别或性取向。这两个角色是谁，由您上传的两张照片决定：异性情侣、
同性情侣，或者您不想给关系贴标签的两个人，跑的都是同一套模板。

其中包含「换成爱人」那句可替换文案。

## 能用的两张照片

**第一张——幸存者。** 肩部以上，正面朝镜头，日光或均匀的室内光。不要重滤镜，不要墨镜，
不要帽檐压住眼睛。这张脸会在四个镜头里被反复重绘，所以一张清楚的正脸比一张好看的照片有用
得多。

**第二张——爱人。** 要求相同，甚至更高：这张脸要扛住第二幕的亡者妆容，还要扛住第四幕的硬
切。眼睛、下颌线、发际线都看得清的照片，价值远高于侧脸的抓拍。

对情侣来说，比任何其他主体都更要紧的两点：**两张照片的亮度与色调要接近**（一张阳光海滩加
一张昏暗室内，会把模型推向自创第三种打光），以及**别把两人的合照当成参考照**——一张图里有
两张脸，模型就无从判断哪张脸该演哪个角色。

## 情侣成片常崩在哪，以及各自的解法

| 您拿到的结果                         | 对应的解法                                                                         |
| ------------------------------------ | ---------------------------------------------------------------------------------- |
| 两张脸在片中合成一张「中等长相」     | 按角色名把每张脸锁定到各自的参考照（角色 A、角色 B），而不是写「这对情侣」         |
| 爱人的发型或下颌线被幸存者那边带跑了 | 在身份锁定句里点名发型与身形比例，并在最后一幕里再说一遍                           |
| 爱人保住了，幸存者的脸崩了           | 幸存者也需要自己的锁定——脸型、发型、身形比例对齐第一张参考照                       |
| 拥抱时有一人在另一人背后或身侧       | 保留朝向条款：爱人始终面朝幸存者，绝不绕到背后                                     |
| 结尾像是两段不相干的素材             | 把连续性写在拥抱本身上：同手臂、同距离、同运动方向跨过剪辑点                       |
| 那次跑动读起来像攻击                 | 两道保险都要留：跑动前的「并不攻击」，以及覆盖四幕的「唯一的接触就是跑进怀里拥抱」 |

## 为什么丧尸化的爱人会靠近，而不是袭击

因为拥抱就是这条片子的主题。一次冲锋会把第三幕变成搏斗，那张开的双臂也就不再是选择，而
成了自卫。整张节拍表建立在两件事上：幸存者先放下武器，以及爱人在冲过来之前，浑浊的眼里闪
过一丝熟悉的东西。

第二个原因更现实：四幕里没有任何过度血腥、伤口特写、撕咬或血浆。这份克制让一条情侣成片是
您敢发到短视频平台上的东西，也是这个趋势读起来像「穿了恐怖片外衣的爱情故事」、而不是相反的
原因。
